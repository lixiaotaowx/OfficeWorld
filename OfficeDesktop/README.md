# iruler dream Windows 客户端

桌面版连接 https://115.159.43.237/，与浏览器共用服务、账号和协作空间。
桌面与浏览器各自保存登录；同一账号新登录会按现有规则顶下旧登录。

## 使用
- 无边框窗口、定制菜单与暖白/深灰/金黄桌面主题；顶部可拖动、双击最大化。
- 声音与共享 → 设备管理，打开Windows声音设置，选择输出与输入设备。
- 双击 `iruler-dream-0.1.4-Windows-x64.exe`，无需另外安装 Node.js。
- 首次登录后使用 Windows 系统加密保存登录信息；下次恢复会话，断网以5–30秒间隔重试。
- 主动退出清除保存信息，被其他设备顶下线后不自动抢登录。
- 点击通话开麦时应用自动处理本站麦克风权限，不弹网页授权框。
- 登录并恢复自己的工位后，自动显示主屏幕低清预览，每3秒一张，最长边480像素。
- 右键三维场景中自己的显示器可切换物理屏幕，记住选择；屏幕拔掉时回退主屏。
- 工位预览可暂停；高清私聊/会议共享仍需选择窗口或屏幕，麦克风独立。
- 不申请摄像头、不采集系统声音、不新增录制或保存音视频功能。
- 点击关闭按钮会隐藏到系统托盘，后台继续运行，保留连接、通话和共享。
- 单击或双击托盘图标恢复窗口；右键托盘选择“退出 iruler dream”才结束程序、通话和采集。
- 再次双击EXE会恢复已有窗口，不会启动第二份客户端。
- Windows禁用麦克风时，从“声音与共享 → Windows 麦克风设置”打开系统设置。
- 浏览器仍访问原网址，使用浏览器原生麦克风授权和屏幕选择器。客户端不能改变浏览器权限政策。
- **文件直传**：把文件从资源管理器拖到任务栏头像条上某个人的头像上就开始发送，**不需要对方同意**，
  直接落进**对方在设置里选好的接收文件夹**（默认 `<系统下载>/iruler dream`，第一次会自动建出来）。
  发送方和接收方都有两套进度：Windows 任务栏按钮上的原生进度条，以及头像条底部那条细线；
  传完之后程序左下角会留一张卡片，带「打开」和「打开文件夹」，也可以从系统通知点回窗口。
  网页登录的同事也能收，但只能落到浏览器的下载文件夹、没有系统进度条。
  暂不支持发送文件夹（请打包后再发），单个文件上限 2 GB。

## 开发与打包
```powershell
npm install
node node_modules/electron/install.js
npm test
npm run dist
```
输出：`../Build/OfficeDesktopRelease/`。Electron和打包工具均固定版本。
网页内容从正式站点加载，因此需联网；网页功能更新无需重新下载exe。
Electron运行时更新仍需重新打包，本版不含自动更新服务。

## 权限边界
仅允许正式HTTPS主框架使用麦克风，拒绝其他站点、子框架、摄像头及其他权限。
低清预览是用户要求的默认行为，登录且有工位才运行；高清共享需用户操作并选择内容。
预加载仅向正式主窗口提供限定的显示器/截图/加密登录接口，不暴露Node.js或任意文件系统。
保持Chromium沙箱、上下文隔离和证书检查。
本版本未配置商业代码签名，Windows可能显示未知发布者。
