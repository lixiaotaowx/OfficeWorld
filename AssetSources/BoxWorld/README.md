# Box World · 原创基础方块部件

2026-09-29 为用户的新可搭建三维空间制作。

- `BoxWorld_Parts.blend`：68 个命名集合（原20件＋休闲影音区42件＋建筑6件）；拱门按最新要求为外方内圆的半圆洞口挤出网格，其他部件保持基础 cube，无倒角。
- `Models/`：68 件可独立复用的 GLB，米制单位、底部原点；原始角色和办公室资产未替换。
- `BoxParts.json`：从网页实际几何导出的盒子参数，以及圆拱门的真实顶点与三角面。
- `References/Shared_Video_Lounge.png`：用户提供的造型/物品种类参考，模型为原创方块化制作，不含截图纹理。
- `tools/export_box_library.cjs`：从网页几何导出参数；先运行此脚本，再运行下方 Blender 构建。
- `tools/build_box_world.py`：在 Blender 5.1 中创建可编辑资产库。
- 网页共用一个单位 BoxGeometry，不下载整间办公室模型或部件纹理。

2026-09-30：流动箭头改为单支普通箭头，细杆与三角尖头使用无倒角挤出轮廓，0.5×0.125×0.75米；沿局部+Z轻推8cm后回位，网页周期1.4秒，Blender含对应位移关键帧。总数68件。宝箱木板与饰带分离2cm，避免共面闪烁。同步参考图的奶油、蜜桃、蓝紫、橄榄配色。网页所有部件可用局部三轴手柄按25cm网格缩放，基础库保留原始米制尺寸。

所有几何由项目自行生成，没有引用外部作者素材或第三方许可资产。
Blender 采用 Z-up，网页采用 Y-up；转换为 `(x, -z, y)`。
这是一套新的建造部件，未修改或覆盖用户既有 Blender / UE 工程。

新增建筑：窄楼梯1×1×2米、高楼梯2×2×4米、窄高楼梯1×2×4米、双坡屋顶4×1×4米、飘旗屋顶4×2.25×4米（宽×高×深）。楼梯踏步统一高0.25米、深0.5米；屋顶为纯Box阶梯双坡。小旗由8片薄Box组成，Blender与GLB带循环摆动动画；网页实时动画独立实现，旗面不参与碰撞。
