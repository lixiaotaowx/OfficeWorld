# 薄片尺子头像素材包 v2

用户参考：微信图片_20260928183208_1799_166.png。
用户校正：尺子本体几乎没有厚度，不使用圆鼓的厚积木造型。

## 文件

- 六张 `happy / busy / sleepy / focused / wave / away.png`：带真实 RGBA alpha 的表情底图。
- `layers/`：19 张独立透明配饰，不含角色身体或背景。
- `prompts-v2.json`：内置 image_gen 使用的完整生成提示词。
- `preview.png`：应用实际合成效果，含明暗背景与多种配色。

## 组装

以 512×512 为合成坐标系，将表情 PNG 等比缩放铺到完整画布。
困倦图校准：绕源锚点 (0.537, 0.458) 缩放 0.925，再移至目标锚点 (0.54, 0.475)。
其余表情保持原画布。先画表情底图，再按头发、帽子、胡子、眼镜顺序叠加
`layers/` 内选中的 PNG（整张图缩放到 512×512）。配件位置已校准到这个坐标系。
帽子属于头像专用比例：礼帽略收高，派对帽压低以避免方形头像裁掉帽尖。
状态灯、消息角标、选中框由 UI 绘制，未烘焙到 PNG。

表情底图包含脸和手势，配饰独立；暂不支持任意交换单独的嘴、眼睛、手套部件。
10 种配色由应用对金黄色尺子板染色，眼睛、嘴、手套和配饰保留原色。

## 应用接线

状态栏头像使用场景同一份配色和配件数据，所有成员共用姿势库。
设置 → 我的角色仅提供只读状态栏预览，不提供独立的头像表情选择。
在座开心、通话/共享忙碌、离座休息、问候时挥手。
困倦/专注保留为公共素材，当前没有自动触发；不推断用户情绪。
旧账号中 expression 字段被忽略，配色和配饰继续保留。

## 制作与来源

表情底图由内置 image_gen 按用户参考图生成并按“薄片”要求修订，未使用 CLI/API fallback。
配饰来自本项目的 19 件配饰模型，由 Three.js 透明渲染输出。
源码：OfficeWeb/src/expressionPortrait.ts 与 test/browser/render-expression-layers.cjs。
厚版草稿未进入此素材包或线上头像。
