## 当前修订：状态栏共用姿势与场景换装

移除独立表情选择及账号 expression 字段。头像直接使用场景的配色、帽子、头发、胡子、眼镜，
所有成员共用按状态选择的姿势库。设置只展示同装扮的在座、忙碌、打招呼预览。
旧 expression 字段被忽略，不影响原配饰。困倦/专注素材保留，尚无业务触发条件。
以下为首次交付记录，其中个人表情选择已由本修订取代。

# 2026-09-28 薄片尺子透明表情与配饰组装

用户参考：微信图片_20260928183208_1799_166.png。
追加校正：尺子本体没有明显厚度，不能生成厚积木。

## 交付

- 六种静态 RGBA PNG：开心、忙碌、困倦、专注、打招呼、休息。
- 全部沿薄片本体、相同倾角与眉眼风格制作；厚版草稿未用于网站。
- 19 件独立 RGBA 配饰层；10 种角色配色由合成器调整板身色素。
- 设置 → 我的角色 → 头像表情。选择随账号存储和广播；旧客户端桥由 character 字符串保留完整外观。
- 自动模式按在座/通话共享/离座/问候切换开心/忙碌/休息/挥手；困倦不自动推断。
- 表情底图包含面部与手势，配饰独立。逐帧动画、嘴眼手的任意单独交换未实现。

## 文件与来源

应用素材：`OfficeWeb/public/assets/avatars/expressions-v2/`。
合成器：`OfficeWeb/src/expressionPortrait.ts`。
配件导出：`OfficeWeb/test/browser/render-expression-layers.cjs`。
素材包：`Build/Ruler_Expression_Kit_v2.zip`，包括 6 张底图、19 张配饰层、组装说明、预览与完整提示词。
提示词与制作说明：`AssetSources/Characters/RulerMascot/expressions-v1/prompts-v2.json`、`README-v2.md`。

表情由内置 image_gen 根据用户提供的参考图生成，未调用 CLI 或额外 API 密钥。
配饰层由现有项目模型透明渲染得到。生成 alpha 被保留；未把棋盘格当成透明背景。
派对帽、礼帽使用头像专用高度，防止帽尖裁切；困倦图作统一锚点校准。
