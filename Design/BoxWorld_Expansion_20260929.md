# 方块世界扩展 · 2026-09-29

用户要求新增拱形、可上楼的楼梯、继续向外铺地面；组件 UI 要更矮；建筑允许违反物理、只支撑一个角和悬空。

## 实现

- 第 20 种部件为方块拱门，仍全部使用基础 Box，无倒角；门洞可行走。
- 从实际部件盒子生成稀疏空间碰撞表。每步采样高度，25cm 台阶可上下，薄墙、地板边缘和头顶净空参与检测。
- 点击寻路使用带高度的网格，可从侧面绕到楼梯入口；WASD 使用同一套支撑高度。
- 行走时逐帧重新检测协作中的建筑变化。位置广播包含 y；旧客户端不带 y 时仍按 0 处理。
- 地板不再受到 30×24m 岛屿边界和 600 件装饰上限限制。点击已有地板边缘会同层接出一块。
- 放置不做承重、重心或连接检查。允许悬挑、单角柱支撑、空中独立部件。
- 部件 UI 去掉大标题和尺寸副行，缩略图缩小；类别和颜色合并，状态及开关并入操作栏。
- Blender 源文件重新生成，20 个可编辑命名集合，与网页几何一致。

## 边界

地面可持续向外延展，实际总量仍受存档容量（16MB）和设备资源限制；不是预先分配无限几何。
保留现有工位通道保护、12m 建造高度和 600 件非地板装饰限制。
角色走在已搭建的地板上，不在虚空中飞行；建筑没有重力模拟。跳跃、展示屏视频、自建工位预览继续单列 TODO。
