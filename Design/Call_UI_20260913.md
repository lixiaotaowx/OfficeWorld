# 会议状态与双向屏幕邀请

## 实现
- 保留此前已上线的 LiveKit 2.17.2 兼容修复、房间世代隔离、排队发布与取消采集处理。
- 旧 session-panel 在只有会议、没有私聊会话时渲染空白背景；改为仅有实际会话或待回应邀请时显示。
- 会议收起后显示常驻“你仍在会议中”、媒体连接状态、麦克风和屏幕状态、返回会议与退出会议入口。退出有确认，结束后移除提示。
- 新私聊默认开麦，按钮读取实际发布状态；静音通过当前房间 publication 控制，操作防重入，开启失败不假报已开启。
- 请求看屏幕不要求对方先开始共享；对方接受后先选屏再确认。分享自己的屏幕则由发起者先选屏，接收者同意后观看。
- 新的定向采集不广播公共缩略图；已有公共共享复用时仍保留其原共享范围。高清观看始终需要对方同意。
- 请求支持等待、取消、拒绝、过期和断线清理；停止单个会话不停止其他已授权会话。屏幕采集小窗保留明确的停止共享按钮。
- 共享小窗移到场景左下，避免盖住成员区的语音和屏幕邀请按钮。

- 51项自动测试通过，TypeScript和生产构建通过，修改文件均不超过500行。
- 两个隔离账号经真实VPS LiveKit：双向音频、5次会议开关麦克风、3次会议共享启停、反向共享、重进、短暂断网恢复通过；无PC manager/publisher异常。
- 私聊双向音频及3次静音/取消静音、屏幕重复发布与停止通过。
- 真实界面两个方向的屏幕邀请均收到远端视频；私聊默认开启与按钮三次切换通过。
- 桌面截图 Build/meeting-presence-desktop.png；移动端 Build/meeting-presence-mobile.png。收起、返回、退出和提示清理通过。
- 使用声音振荡器和动态画布作为输入，经真实SFU；没有采集用户桌面或录制用户声音。这不是跨网络真人设备验收。
