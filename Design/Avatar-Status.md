# 2026-10-12 头像公示状态

用户要求：在任务栏自己的头像上右键或单击，出现“加状态”按钮；发布吃饭、外出、报销、文件准备等信息。

- 单击、右键只在自己的头像上打开状态菜单；有内容时显示“修改状态”。
- 编辑器位于主窗口，入口命令会唤起主窗口。头像条原生窗口保持不可聚焦，避免破坏穿透、悬停和中文输入。
- 提供四个快捷文字及40字自定义内容，可修改、清除。保留到主动修改或清除，无自动到期。
- 每个头像上方显示紧凑气泡，最多两行；悬停卡片展示完整文字。相邻气泡不重叠，顶置任务栏方向向下。
- 主窗口每5秒读取已确认状态，推送给头像条；头像条仍不连接业务接口或 Socket。
- `presence-status.mjs` 提供登录态 GET / POST `/api/presence-status`，身份取认证会话，忽略请求中的其他账号 ID；写入 `presence-status.json`，先临时文件再原子替换。该文件是运行数据，不得纳入部署覆盖。
- `DockPerson.status` 必须经过 `dock-bridge.cjs` 白名单转发；`status` 命令经过既有可信窗口校验，主窗口还校验 personId 是自身 Socket ID。
- 保存失败留在编辑器、保留文字和错误提示；不提前显示未确认内容。
