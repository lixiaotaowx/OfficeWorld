| 表情 | 自动条件 |
| --- | --- |
| 忙碌 | 最近 10 秒至少 6 个秒段有输入；忙碌信号保持 8 秒，持续活动会续期 |
| 困倦 | 连续离座达到 5 分钟 |
| 开心 | 本次连接在线超过 10 分钟，且在座、非忙碌、无通话/共享 |

| 专注 | 通话/会议/高清共享中，或刚上线未达到开心条件 |
| 招手 | 原有临时打招呼交互 |

优先级：临时招手 → 通话/共享专注 → 离座/困倦 → 忙碌 → 开心 → 初始专注。
招手是既有交互反馈；自动活跃状态由服务端统一广播给全体在线用户。
重连后本次在线计时重新开始。离线者沿用原规则从在线头像条移除。

浏览器只感知本窗口键鼠/滚轮/触摸。桌面客户端通过已有 systemIdle 桥每两秒采样，
以连续低系统空闲时间推断持续操作，不能精确计数其他应用的按键次数。
仅上传 atDesk、busy、idleMs，不记录按键内容或指针轨迹。
旧桌面桥会丢弃新增对象字段，自动表情随已有 character 的 look JSON 传递，
不写入账号外观、不改变配饰身份、不要求更新安装包。
