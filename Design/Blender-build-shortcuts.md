# 移动模式的 Blender 风格快捷键（2026-10-10）

工作目录：`G:\C\wendang\ChatGPT\youxi`。本轮修改的是 `OfficeWeb` 的建造工具。

| 操作 | 快捷键 / 交互 |
| --- | --- |
| 切换模式 | `Tab` 在漫游 / 移动间切换；返回漫游取消未确认的变换并清掉选择 |
| 创建物体 | 漫游 / 移动下 `Shift+A`；放下一件后回到创建前模式，传送点回漫游 |
| 复制并移动 | `Shift+D`，随后可立即按轴键；服务端复制尚未返回时保留后续输入 |
| 移动 | `G`，鼠标默认沿 XZ 地面移动 |
| 缩放 | `S`，默认均匀缩放 |
| 旋转 | `R` 或用户指定的 `2`，默认绕 Y 轴旋转 |
| 锁定轴 | 变换中按 `X/Y/Z`；同一个轴连续按：世界轴 → 局部轴 → 自由 |
| 锁定平面 | 移动 / 缩放中按 `Shift+X/Y/Z`，排除该轴 |
| 数字输入 | 变换中直接输入；支持负号、小数和 Backspace 编辑。移动单位米、旋转单位度、缩放输入倍数 |
| 确认 | 左键或 Enter；确认前不写入存档 |
| 取消 | 右键或 Esc；保留选择与移动模式。再次 Esc 返回漫游 |
| 慢速微调 | 鼠标变换时按住 Shift，速度降为 1/10；按下 / 松开不跳位置，最终仍遵守网格 |
| 多选 | Shift 点击增减；`A` 全选，`Alt+A` 取消全选 |
| 聚焦选中 | `F` 或小键盘小数点；无选中时沿用悬停聚焦 |
| 更改颜色 | 移动模式选中后，坐标轴右上方的小圆按钮；显示当前配色，点击打开七色色板 |
| 删除与撤销 | Delete / Backspace；Ctrl+Z 撤销，Ctrl+Shift+Z / Ctrl+Y 重做 |

例子：`G → X → 2 → Enter` 沿世界 X 移动 2 米；`S → 2 → Enter` 放大两倍；
`2 → Y → 9 → 0 → Enter` 绕 Y 旋转 90°。变换已经开始之后，数字 `2` 是数值输入。
没有锁轴的数字移动沿鼠标给出的方向；尚无移动方向时取 X，排除 X 的平面则取 Z。

## 项目约束与状态恢复

- 保留现有 25 厘米网格、结构件高度落格与家具精确支撑高度；尺寸仅对受缩放影响的轴取整。
- 保留现有 90° 旋转契约。45° 等不支持的数值会提示并停留在预览态，可修正或取消。
- 沿用项目世界坐标，**Y 为向上**，不改为 Blender 的 Z-up；缩放不支持负倍数镜像。
- 多选按组中心变换位置与朝向 / 尺寸，使用原有 `moveMany` 原子保存；失败整组回退。
- 取消复制后的移动只取消摆放，副本保留原位；可通过撤销删除副本。复制请求仍沿用已有服务端语义。
- 失焦、模式切换、部件版本冲突、销毁均退出预览并释放相机锁。聊天输入与对话框不响应建造快捷键。
- 安装模式的 `Q/R/X/Z` 旧旋转操作保留；移动模式的轴键由当前变换解释。
- 不增加新的三维文字贴片或底部提示行，复用现有状态提示。

交互依据：[Blender 轴约束](https://docs.blender.org/manual/en/5.2/scene_layout/object/editing/transform/control/axis_locking.html)。
本轮覆盖常用物体变换与选择；未实现 Blender 的网格编辑、挤出、镜像、吸附目标菜单或全部快捷键。
