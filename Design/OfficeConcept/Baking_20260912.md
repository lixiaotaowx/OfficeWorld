# Selective baking and seated character fixes

Source: `AssetSources/OfficeConcept/备份.blend`.
Immutable pre-bake backup: `备份_烘焙前_20260912.blend` in that directory.
Editable result: `备份_独立UV烘焙_20260912.blend`.

- Each of 424 mesh objects received its own mesh datablock and Smart UV Project
  layout. Original shading UVs remain preserved separately.
- Final selection: 131 independent baked images; 293 objects retain source
  materials, including glass, foliage alpha, displays and small frame parts.
- Final sizes: ten 2048, fifty-one 1024, fifty-six 512, fourteen 256.
- Each object was baked alone, at 96 Cycles samples. No baked image was connected
  while any object was still baking. Source shaders still handle secondary rays
  in the editable Blender preview, avoiding double illumination.
- Progress/manifests and PNG masters: `AssetSources/OfficeConcept/Bakes_20260912`.
  First-pass unused images remain offline and are not included in the web GLB.
- Modifiers that replace materials required evaluated export meshes. Verified
  the final GLB contains all 131 baked materials, rather than the initial 43.
- Web display copies use Blender's display transform; the browser treats baked
  surfaces as unlit without another tone transform. Transparent source materials
  remain separate. Draco geometry and WebP images reduce the 27,876,012-byte
  uncompressed export to 10,009,624 bytes, excluding the cached Draco decoder.
- Original source meshes and modifiers are restored after disposable export
  copies are removed. Current edited chair geometry is included.

Sitting fixes:

- GLTFLoader removes periods in rig names; limb lookup now supports that.
- Foot controls are independent from shins. They are explicitly placed at the
  shin endpoints, preserving length and resting foot orientation.
- Two-bone foot placement adapts each character to its ground contact height
  while the hips stay seated. The crossed raised leg is exempt from grounding.
- Torso lean is applied before arms. Local and remote players share the fixes.
- 21 character rigs × six poses passed length, stability, bend and grounding
  checks. The actual exported chair was rendered with a seated character.
